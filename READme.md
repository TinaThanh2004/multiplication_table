## What I Learned
In this exercise, I learned how to use GitHub to create a repo and upload my project files.
I also practiced writing JavaScript that creates a multiplication table using loops and connecting it to my HTML page.
It was cool to see how the code actually runs and changes what shows up on the page. And scary.

## What I Found Difficult
At first, I had a little trouble getting the button to actually generate the table.
I had to check a few times that my JavaScript file was linked right.
I also got confused for a bit about how to push updates and see them show up on GitHub.
But once I tried it a couple of times, it started to make more sense.
Overall, it was a good intro to using GitHub and connecting code files together.
